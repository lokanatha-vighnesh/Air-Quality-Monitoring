# AirSense – Air Quality Monitoring App

AirSense is an Android application designed to help users monitor indoor and outdoor air quality in one place. It provides air-quality information, visualizes environmental conditions, predicts future indoor gas levels, and offers alerts and recommendations to help users maintain a healthier environment.

## Features

- **Indoor Air Monitoring:** Monitors gas and smoke levels using an MQ-2 sensor connected to an ESP32.
- **Outdoor Air Quality:** Displays outdoor pollution information using the Open-Meteo API.
- **Live Dashboard:** View indoor and outdoor air-quality conditions in one place.
- **Air Quality Trends:** Visualize historical readings through graphs.
- **Air Quality Forecasting:** Predict future indoor gas levels using machine learning.
- **Alerts and Recommendations:** Get notifications and suggestions based on air-quality conditions.
- **Location Support:** View outdoor air-quality information for selected locations.
- **Reports:** Generate reports and export recorded data.
